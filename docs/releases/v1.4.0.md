# Qurioso 1.4.0

This update adds cloud sync and reworks the interface so that each button says what it does.

- **Cloud sync:** connect Google Drive, Dropbox or OneDrive in Settings to keep quizzes and their images aligned between your devices. Qurioso has no server: data go from your device to a file in your own cloud space. Local video files, drafts, PINs, participants and scores are not synced. On the desktop, sign-in opens in the system browser and the refresh token stays encrypted on the computer; on the website it is available at qurioso.it. Microsoft accounts: personal accounts only.
- **Buttons with one meaning:** orange marks the single main action of each screen, outlined buttons are the other actions, red buttons delete, discard or disconnect. Disabled buttons now look disabled, and file pickers are translated.
- **One name per mode:** *Attività in classe* and *Quiz sui dispositivi* (Classroom activities / Device quizzes, Klassenaktivitäten / Quiz auf den Geräten) everywhere: library, cards, lobby, website, settings, desktop menu and guide.
- **Projected question:** on a projector the question and answers fill the screen, and the timer fits three-digit times.
- **Lobby:** the PIN appears once, the start button explains why the quiz cannot start yet, and test participants are a quiet link.
- **Clearer words:** Italian labels use sentence case, technical terms such as "HTTP/WS" are gone, and Cloudflare details are in a collapsible section.
- **Fix:** the desktop app could show a blank page when reopening a page it had already loaded.
- **Privacy:** the privacy policy is at https://qurioso.it/privacy.html.

Validation: TypeScript checks, 155 automated tests, production web/server builds and the desktop smoke test passed. Cloud sign-in was tested manually in the Linux desktop app; sign-in on the website and sync between two devices are still to be tested with real accounts.

Cloudflare sharing remains optional and experimental. Desktop installers and the experimental Android APK are built by GitHub Actions. Windows and macOS runtime acceptance testing remains separate from CI packaging.
