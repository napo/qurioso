# Qurioso 1.2.0

This release separates the web and desktop workspaces and improves network games, teacher presentation and participant results.

- **Web and desktop workspaces:** the web app focuses on classroom lessons and quiz creation. Desktop includes classroom lessons and quizzes on participants' devices, with a clear mode selector and one primary action per quiz.
- **Optional Internet access through Cloudflare:** the desktop app can share a game outside the LAN without an account. The first activation downloads and verifies the official cloudflared component. Connection states, download progress, errors, documentation and service privacy links remain visible. Once connected, the displayed address, copied address and both QR views use the public URL; interruption or shutdown restores LAN addresses. Internet preferences do not start a tunnel by themselves.
- **Multilingual tutorial guide:** open Guide from the home page, library or settings for 11 step-by-step tutorials in Italian, English and German. Chapter links, browser history and language changes preserve the current tutorial position.
- **Settings and library tools:** quiz creation, ZIP backup and restore, and question import are available from settings, with localized runtime and installation explanations. Web and desktop libraries remain separate; backups transfer content between them.
- **Participant results:** the final ranking offers sharing of a personal result PNG and closing the window. Device sharing falls back to downloading the image when unavailable. A read-only result can survive a refresh in the same tab, without retaining game credentials.
- **Teacher video and phone answers:** video competitions support fullscreen and Escape. Compact phone controls use the same letters, colors and symbols as the teacher's screen and fit without scrolling; complete answer text remains available to assistive technology.
- **Linux development builds:** unpacked local builds prepare their sandbox helper for user-namespace sandboxing, avoiding the incorrect user-owned SUID helper. Installed packages retain installer-managed permissions.

Cloudflare Quick Tunnels are experimental, require an Internet connection and do not guarantee availability. Game traffic passes through Cloudflare while sharing is active. Keep the teacher app running. LAN games remain available without Cloudflare. See the [Internet sharing guide](https://github.com/napo/qurioso/blob/v1.2.0/docs/INTERNET_SHARING.md).

Validation: TypeScript checks, 116 automated tests, Web/PWA and desktop production builds, and the packaged Linux application's two-launch smoke test, including network play, presenter layouts, recovery, imports, backups, localized guide/settings and server shutdown. Windows and macOS installers are built by CI and still require platform-specific user testing.
