# Qurioso 1.2.1

This update makes the included volcano quiz available in existing libraries and improves phone answers, final results and Internet sharing controls.

- **Included volcano quiz:** “Tipi di vulcani con geopop” remains visible alongside previously saved libraries, without replacing personal edits or duplicating an existing quiz ID. Desktop users can choose **Quiz on participants' devices → Network video quiz** to play its eleven saved checkpoints.
- **Complete answers on phones:** answer text stays visible and fits the available cell through measured font sizing. The grid fills the usable viewport and adapts to portrait, landscape and dense sets of answers. Symbols retain their colors with transparent backgrounds on participant and teacher screens.
- **Complete result image:** the shared PNG includes the quiz title, the player's name and selected avatar, podium and full ranking. Its height adapts to the ranking. The sharing hint explains that participant names are included; game credentials and the session PIN remain excluded.
- **Per-game Cloudflare controls:** the global preference is removed from Settings. A new network game offers optional Internet sharing. Starting it closes the modal and reports progress on the teacher screen. Outside fullscreen, the ON/OFF switch stops sharing and directly restarts an already authorized tunnel. Displayed links and QR codes continue to follow the active public address or return to LAN when sharing stops.
- **Illustrated multilingual guide:** all eleven tutorials include actual application screenshots using the volcano quiz, separately captured in Italian, English and German. Thirty-three screenshots include teacher, editor, classroom, participant and result examples, with an enlarged image view.

Validation: TypeScript checks, 118 automated tests, production builds and packaged Linux verification covering complete answer text with 2, 4, 6 and 12 options, portrait/landscape layouts, classic and video gameplay, recovery, Cloudflare controls, guide navigation, imports and backups. Windows and macOS installers are built by CI; platform-specific runtime acceptance testing remains necessary.

Cloudflare sharing remains optional and experimental. Read the [Internet sharing guide](https://github.com/napo/qurioso/blob/v1.2.1/docs/INTERNET_SHARING.md) for external service behavior, component downloads and troubleshooting.
