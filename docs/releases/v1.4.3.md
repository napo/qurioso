# Qurioso 1.4.3

This update closes a way for students to disrupt a network quiz and makes the join address easier to read aloud and type.

- **Teacher features stay on the teacher's computer:** other devices on the LAN, like visitors through Cloudflare, can only join and play. Creating, controlling or ending games, and the server information, are refused from any other device. Before, a student could open the library from the shared address, start games on the teacher's server, or fill its limits until no new game could start.
- **Students land on the PIN form:** opening the address from another device goes straight to participant mode, never to the library or the landing page.
- **DNS rebinding:** a web page opened on the teacher's computer can no longer reach teacher features by pointing its own hostname at the local server.
- **Simpler address:** the lobby shows only `192.168.1.7:54321` or `name.trycloudflare.com`, without `http://`. Copying still gives the full link, and the QR still includes the PIN.

The teacher screen now works only on the computer running Qurioso. Opening the LAN address on another device, such as a tablet, gives the participant screen.

Validation: TypeScript checks, 161 automated tests (including requests over the real LAN interface and a rebound hostname), production web/server builds and the desktop smoke test passed. Windows and macOS were not tested by hand.

Cloudflare sharing remains optional and experimental. Desktop installers and the experimental Android APK are built by GitHub Actions.
