# Qurioso 1.3.3

This update prepares the desktop app for the move of the project to the `qurioso-it` GitHub organization.

- **Desktop updates:** the app now looks for new versions in `qurioso-it/qurioso` and falls back to `napo/qurioso` while the new repository does not exist. Installers are accepted only from these two repositories. Install this version to keep receiving automatic updates after the move; earlier versions will need a manual download.

Validation: TypeScript checks, 133 automated tests and production web/server builds passed. The move itself is simulated in the automated tests and has not been exercised with an installed app.

Cloudflare sharing remains optional and experimental. Desktop installers and the experimental Android APK are built by GitHub Actions. Windows and macOS runtime acceptance testing remains separate from CI packaging.
