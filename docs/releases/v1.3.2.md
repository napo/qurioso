# Qurioso 1.3.2

This update adds direct links to classroom activities and fixes the final podium of network quizzes.

- **Classroom links:** `?app=classroom&quiz=<slug>` opens a quiz directly in the classroom activity, for demos and shared lessons, for example `https://qurioso.it/?app=classroom&quiz=tipi-di-vulcani`. The link accepts an included quiz, a quiz in the local library or a quiz published with the website in `quizzes/<slug>.json`, which is validated before it opens. A missing quiz opens the library with an explanation.
- **Final podium:** correct-answer badges, accuracy and CSV/JSON exports now use the real number of questions in the quiz instead of a fixed total of 10.

Validation: TypeScript checks, 132 automated tests and production web/server builds passed.

Cloudflare sharing remains optional and experimental. Desktop installers and the experimental Android APK are built by GitHub Actions. Windows and macOS runtime acceptance testing remains separate from CI packaging.
