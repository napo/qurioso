# Qurioso 1.5.0

This update adds questions written with an AI assistant without any key, makes cloud sync safer and lighter, and makes joining faster on students' phones.

- **Questions from an AI assistant, no key needed:** in Import questions, paste a video transcript or lesson text and copy the request Qurioso prepares into the assistant you already use (ChatGPT, Claude, Gemini…). Paste its answer back: the questions go through the usual checks and preview. Qurioso contacts no service. Read the questions before using them: the assistant can be wrong.
- **Time in the video:** imported questions can carry a time (`mm:ss`, `h:mm:ss` or seconds). In a video quiz it becomes the question's checkpoint.
- **Safer cloud sync:** an edit can no longer be undone when two devices write to Google Drive at the same moment; two devices connecting at once no longer create two Drive files; an edit now wins over a deletion made on another device.
- **Lighter cloud sync:** when nothing changed on either side, the library file is not downloaded again.
- **Faster joining:** students' phones load only the join and game screens, about a sixth of the previous download.
- **Lobby:** the instructions now match the new entry: open the address and enter the PIN. Guide screenshots are updated.

Validation: TypeScript checks, 168 automated tests, production web/server builds and the desktop smoke test passed. Cloud sync is still tested only with simulated services, not with real Google Drive, Dropbox or OneDrive accounts. Windows and macOS were not tested by hand.

Cloudflare sharing remains optional and experimental. Desktop installers and the experimental Android APK are built by GitHub Actions.
