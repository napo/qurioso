# Qurioso 1.4.2

This update fixes the problems found by an accessibility audit (axe-core, WCAG 2.1 and 2.2 level AA) of the website and the app.

- **Zoom:** pages can be zoomed on phones and tablets again. Quick repeated taps on an answer button still do not zoom the page.
- **Video controls:** the play/pause, restart and sound buttons of the classroom video player now have names in Italian, English and German, so screen readers can announce them.
- **Contrast:** the step numbers on the website and the small labels of the selected question in the editor are darker and now meet the minimum contrast.
- **Tests:** a new test checks zoom, the contrast of the theme's text colours and the names of the video player buttons.

Validation: TypeScript checks, 159 automated tests, production web/server builds and the desktop smoke test passed. The axe-core audit reports no violations on the website, library, settings, editor, classroom activity, participant join and privacy pages, at desktop and phone sizes. Keyboard-only use, screen readers, the lobby and the projected question were not tested by hand.

Cloudflare sharing remains optional and experimental. Desktop installers and the experimental Android APK are built by GitHub Actions. Windows and macOS runtime acceptance testing remains separate from CI packaging.
