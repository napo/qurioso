# Qurioso 1.6.0

This update adds team games, more question types, class reports and homework assignments.

- **Teams:** choose 2–6 teams in the lobby, let participants pick a team when joining, move them during setup, and see team standings based on average member scores.
- **More question types:** multiple-select, polls and ordering questions work across live games, classroom activities, video quizzes, imports and backups.
- **Question reports:** review class answers question by question, export the report as CSV and start a classroom review of the most-missed questions.
- **Homework:** assign a classic quiz with a deadline from the teacher app. Students can work independently, pause and resume; the server grades answers and the teacher can review and export results. The teacher computer and Qurioso must remain available until the deadline.
- **Participant and lobby improvements:** remove participants, filter offensive nicknames, simplify quiz import and clarify Internet-sharing status.

Cloudflare sharing remains optional and experimental. Desktop installers and the experimental Android APK are built by GitHub Actions.
