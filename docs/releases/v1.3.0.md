# Qurioso 1.3.0

This release expands Italian, English and German support and improves the classroom, desktop and public website experience.

- **Multilingual gameplay and editing:** lobby, participant, quiz editor, video activities, result exports and service messages follow the selected interface language, with English as the fallback for unsupported languages. New English and German sample quizzes are included.
- **Native desktop workspace:** the desktop app has its own workspace shell and navigation. Its native menu and initial interface follow the system language and update when the interface language changes.
- **Classroom presentation:** questions and answers are easier to use with a projector, with keyboard controls and improved presentation layouts.
- **Simpler quiz library:** streamlined cards, mobile layout and navigation make saved quizzes easier to browse. Sample quiz covers are bundled locally, with image fallbacks and updated image credits. New quizzes use Qurioso as their default author.
- **Updated website and guide:** the public website focuses on the project and browser classroom activities, offers a fallback release link when installer availability cannot be verified, and includes refreshed desktop guide screenshots.
- **Dependency cleanup:** the unused Google GenAI dependency and AI Studio metadata have been removed.

Validation: TypeScript checks, 128 automated tests and production web/server builds passed. Desktop installers and the experimental Android APK are built by GitHub Actions. Windows and macOS runtime acceptance testing remains separate from CI packaging.
