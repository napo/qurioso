# Qurioso 1.3.1

This update adds a cooking video quiz and improves Cloudflare sharing across consecutive games.

- **Parmigiana di melanzane:** a new included Italian video quiz with six questions and checkpoints at 0:31, 1:02, 1:48, 2:23, 2:45 and 2:54. It is available in new and existing libraries, without replacing personal edits with the same quiz ID. The cover is embedded for offline use, with its original image credits; YouTube playback requires Internet access.
- **Reuse sharing between games:** leaving a game stops sharing that game while keeping a healthy Cloudflare connector ready for the next one. Enabling sharing in the next game reuses the public address with the new PIN. The server rejects tunnel traffic while no game is shared.
- **Connector lifecycle:** at most one Cloudflare connector runs at a time. Requests wait for a closing connector, and an unfinished connection for another game is replaced. The OFF switch, page reload and app shutdown close the tunnel; a broken idle connector is closed quietly.
- **Verification:** the live Cloudflare smoke script now covers releasing a game and reusing its tunnel.

Validation: TypeScript checks, 129 automated tests and production web/server builds passed.

Cloudflare sharing remains optional and experimental. Desktop installers and the experimental Android APK are built by GitHub Actions. Windows and macOS runtime acceptance testing remains separate from CI packaging.
