# Qurioso 1.4.1

This update refreshes the built-in guide for the interface introduced in 1.4.0.

- **Guide:** the screenshots in Italian, English and German now show the new buttons and the mode names *Attività in classe* and *Quiz sui dispositivi*. The editor screenshot shows Save as available, as it is in the app.
- **Tests:** a new test confirms that a YouTube or Vimeo quiz can be saved even when the video never reports its duration, for example offline.

There are no other changes to the app compared with 1.4.0.

Validation: TypeScript checks, 156 automated tests, production web/server builds and the desktop smoke test passed.

Cloudflare sharing remains optional and experimental. Desktop installers and the experimental Android APK are built by GitHub Actions. Windows and macOS runtime acceptance testing remains separate from CI packaging.
