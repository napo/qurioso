# Qurioso 1.6.1

This update helps teachers notice participants who share a device, and frees shared devices once homework is handed in.

- **Same device warning:** in the lobby and on the homework page, a triangle next to a name means that participant joined from the same browser as another one ("Same device as …"). Each browser keeps a random code that says nothing about the device; the teacher's computer only shows who shares one. It is a hint, not a proof: on a shared tablet it is normal, and a private window gives a new code.
- **Homework on shared devices:** once a student has handed in their homework, leaving forgets them on that device, so the next student with the same PIN starts their own homework. Their answers stay with the teacher. Before handing in, students can still leave and continue later.
- **Privacy:** the privacy policy now explains the device code and how long homework stays on the teacher's computer (until it is deleted, at most 30 days after the deadline).

Also in 1.6.0, not listed in its notes: **Assign randomly** spreads the participants evenly across the teams in the lobby.

Validation: TypeScript checks, 197 automated tests, production web/server builds and the desktop smoke test passed.

Cloudflare sharing remains optional and experimental. Desktop installers and the experimental Android APK are built by GitHub Actions.
